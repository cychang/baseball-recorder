# GameChanger Baseball Records

這是一個本地 SQLite 儲存的棒球紀錄管理系統，主要用途是管理球隊、球員、盃賽與比賽資料，適合本地測試與後續擴充。

## 功能

- 球隊資料管理
- 球員資料管理
- 盃賽資料管理
- 比賽紀錄與比分追蹤
- 儀表板總覽與統計
- SQLite 本地持久化儲存

## 啟動方式

1. 安裝依賴：
   npm install
2. 啟動伺服器：
   npm start
3. 打開瀏覽器：
   http://localhost:3000

## 專案結構

- server.js：後端 API 與 SQLite 資料邏輯
- public/：前端頁面
- data/baseball.db：本地 SQLite 資料庫

## 目前定位

這個版本目標是保留簡單、可用、可擴充的資料模型，適合：

- 本地測試
- 驗證資料結構
- 後續擴充完整球季與比賽事件
