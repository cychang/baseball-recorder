# GameChanger Baseball Records

這是一個本地 SQLite 儲存的棒球紀錄管理系統，主要用途是管理球隊、球員、盃賽、比賽資料與比賽事件，適合本地測試與後續擴充。

## 功能

- 球隊資料管理（只需球隊名稱）
- 球員基本資料管理（球隊由既有球隊下拉選擇，不固定守備位置；成績不手填）
- 盃賽資料管理（只需盃賽名稱與賽季）
- 比賽紀錄與比分追蹤（主客隊由既有球隊下拉選擇）
- 球隊、球員、盃賽、比賽頁以列表為主；新增與編輯才開啟資料 modal
- 比賽開始前建立兩隊 Order 單（打序與先發投手）
- 傳統棒球計分板工作台（line score、壘包鑽石、B/S/O 燈號）
- 比賽事件記錄（系統依打序帶出局半、打者、投手，使用者記錄打席結果、得分、出局、好壞球、壘上狀況與註記）
- 球員成績由逐球事件累加（PA、AB、H、HR、RBI、AVG、OBP、SLG、OPS）
- 由事件時間線衍生比賽比分與勝隊
- 儀表板總覽與統計
- SQLite 本地持久化儲存

## 啟動方式

1. 安裝依賴：
   npm install
2. 啟動伺服器：
   npm start
3. 打開瀏覽器：
   http://localhost:3000

## 範例資料

內建 demo 的三支球隊都至少有 9 名球員，可以排完整 Order 單。系統也會保留一場 `live` 狀態的測試比賽：台北猛虎 vs 桃園海盜，兩隊已有完整 Order 單與先發投手，打開逐球紀錄後可以直接測試第一局上半、目前打者/投手、B/S/O、壘上狀況與 play-by-play 事件累加。

## 專案結構

- server.js：後端 API 與 SQLite 資料邏輯
- public/：前端頁面
- data/baseball.db：本地 SQLite 資料庫

## 目前定位

這個版本目標是保留簡單、可用、可擴充的資料模型，並開始往 GameChanger 類型的即時記錄工具靠近。適合：

- 本地測試
- 驗證資料結構
- 後續擴充完整球季、守位、逐球紀錄與比賽分享

## 產品重心

首頁是逐球紀錄工作台。比賽建立完成後，使用者先設定兩隊 Order 單；開始記錄後，系統依事件推進第幾局上下半、目前打者、目前投手、B/S/O 與壘上狀況。主視覺採傳統棒球 line score、壘包鑽石與好壞球/出局燈號；使用者主要負責輸入這次 play 的結果、得分、出局數、play 後壘包與註記。總覽、球隊、球員、盃賽與比賽管理都是支援資料。

球員頁只維護姓名、球隊與背號。AVG、OPS、HR、RBI 等成績會從 `game_events` 的打席事件即時計算，避免資料和逐球紀錄互相打架。
